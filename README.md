# 地域イベント共創ポータル

> 地域イベントを、ひとつの場所から。

大学生・地域住民・自治会・商店街・NPO が一つのイベントを一緒に運営するための「イベント司令室」ダッシュボードです。
Google Calendar・Discord・Canva・Google Drive・SNS を置き換えず、**イベント単位で入口を一つにまとめます**。

## 画面

| ページ | 内容 |
|---|---|
| ホーム | イベントヘッダー（進捗・分野別信号・開催までの日数）、今日のあなた、これからの予定、Discord、Canva制作物、Drive、SNS、タスク、備品、進捗状況、決定事項、お知らせボード |
| タスク | 登録（タイトル・担当・期限・分野）、自分／チーム、分野フィルタ、状態変更 |
| カレンダー | 月表示（予定＋SNS投稿＋タスク締切の重ね表示）と14日間の予定 |
| 制作物 | Canvaデザインの版・担当・締切・状態、関連タスク・SNS投稿 |
| SNS | 投稿スケジュール（媒体・日時・使用画像・担当・状態） |
| 備品・物品 | 必要数／確保数から状態を自動判定（確保済・一部不足・未確保） |
| 資料 | Google Drive のフォルダ別一覧 |
| 決定事項 | 決定事項 → タスク化、地域の方の「確認しました」 |
| ガントチャート | 分野ごとの期間と完了度、今日の線、開催日 |
| イベント | 開催中・企画中・アーカイブ（昨年の振り返り）、テンプレートから作成 |
| メンバー | 学生・地域・協力団体と連絡手段 |
| 設定・連携 | 各サービスのURL、連携の段階（Lv1〜3）、データの持ち主チェック |

## 設計上のポイント（ブラッシュアップ仕様 v1.1 より）

- **「今日のあなた」を左上に**：期限超過を最上段に赤で表示
- **進捗は1か所に集約**：完了タスクの割合。分野別の信号は「期限超過あり＝要対応／3日以内に期限＝注意」のルールで自動判定
- **フリーチャットは置かない**：会話は Discord。ポータルは全員に届けたい「お知らせ・決定事項」だけを扱い、Discord／地域LINEへ配信
- **役割別の表示**：右上のアカウントから「リーダー・事務局／学生メンバー／地域の方」を切り替え（デモ）。地域の方は閲覧＋「確認しました」のみ
- **ウィンドウの表示切替**：「ウィンドウを編集」で役割ごとに表示を保存
- **スマホ**：下部タブ（ホーム／予定／タスク／制作／その他）。ホームは今日・予定・Discord・Canva・お知らせに絞り、残りは「ほかのウィンドウも表示」で展開

## 技術構成

- Next.js 16（App Router）＋ TypeScript、外部UIライブラリなし（アイコンのみ lucide-react）
- データは現在**デモデータ**で、ブラウザの localStorage に保存（設定ページから初期化可能）。日付は初回表示日を基準に配置
- 次の段階：Supabase（Auth・Postgres・RLS）へ移行、Google Calendar API／Discord Webhook／Canva Connect API／LINE Messaging API 連携

```bash
npm install
npm run dev
```
